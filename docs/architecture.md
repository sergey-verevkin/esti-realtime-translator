# Устройство приложения

## Поток данных

Системный звук → нативный Core Audio tap → PCM → распознавание → завершённые фрагменты → перевод по предложениям → SwiftUI-оверлей и история.

Приложение состоит из трёх независимых частей. Оверлей запускает Python-переводчик, тот запускает распознаватель, который читает нативный захват. Управление остановкой проходит по этой же цепочке с обработкой накопленных фрагментов.

### Захват и распознавание

`capture-transcription/`: Core Audio taps через AudioTee (MIT, закреплённый commit `56ac954369a09318e46b88a6eec33c2d2b0d32a3`), macOS 14.2+. Mono PCM int16, 16 kHz, порции 200 мс. Виртуальный аудиодрайвер не нужен. В CLI можно ограничить захват PID.

Чтение аудио независимо от распознавания; очередь ограничена примерно 20 секундами. Переполнение вызывает явную ошибку, а не скрытый пропуск. В штатном оверлее начало речи определяет Silero VAD v6.2.3, ONNX CPU, около 2,33 МБ весов. Вероятность оценивается кадрами по 32 мс, начало подтверждается тремя последовательными кадрами (96 мс) выше 0,5; для продолжения используется порог 0,35. Кадры обрабатываются непрерывно с сохранением состояния. Пауза 0,8 секунды определяется по отсутствию распознанной речевой активности; в паузе может присутствовать неречевой шум. Аудио перед началом сохраняется на 0,4 секунды. В меню можно вернуть прежний детектор по громкости (порог энергии 0,003). Аудиоконтекст сохраняется до паузы либо максимального окна 16 секунд. Совпадающий префикс повторных проходов закрепляется, незавершённый текст уточняется.

Два проверенных варианта:

- TalTech Whisper large-v3-turbo-et-verbatim-2604 через pywhispercpp / Metal: дообучен на эстонской речи, веса GGML около 1,62 ГБ. В оверлее обновление раз в 3 секунды. Это оконные повторные проходы, не нативная потоковая модель.
- Parakeet TDT V3 INT8 через onnx-asr / CPU: быстрый многоязычный вариант, использует уже установленные в Handy веса только для чтения. Обновление раз в секунду.

Токенные временные метки приблизительные. Предварительные гипотезы могут исправляться. Микрофон, диаризация и автоматическое восстановление после смены устройства не реализованы. Экспериментальный MLX-путь в коде не является проверенным штатным режимом.

### Перевод

`translation/`: NLLB 600M или distilled 1.3B, CTranslate2 CPU INT8, 2 потока, beam 4. Модели загружаются один раз на сессию. Установщики закрепляют ревизии и проверяют SHA256; provenance хранится рядом с весами. Профили оверлея — эстонский → русский и английский → русский; выбор английского Zipformer одновременно задаёт английский язык NLLB. Автоматическое определение языка внутри других ASR не меняет выбранный профиль.

Переводчик накапливает только подтверждённые ASR-фрагменты. Каждое законченное предложение сразу формирует отдельную карточку, даже если несколько предложений пришли одним ASR-сообщением. Незавершённый хвост остаётся в накопителе и объединяется со следующим фрагментом. Короткие законченные предложения также показываются отдельно. При отсутствии пунктуации или очень длинном предложении текст делится по лимиту: 24 слова в обычном режиме, 48 в режиме «Больше контекста». Пауза, остановка и граница аудиоокна завершают оставшийся хвост. Предварительный перевод появляется через 2,5 или 6 секунд и не удаляет контекст. Разделение учитывает распространённые эстонские сокращения и числа; оно зависит от пунктуации ASR и не гарантирует идеальных лингвистических границ.

На 13 подготовленных фразах M1: медиана 600M — около 0,64 с, 1.3B — 1,25 с; это время перевода, не общая задержка субтитров. У обеих моделей остаются ошибки в именах, модальности и эстонских выражениях времени. Пользователь предпочёл 600M после сравнения. OPUS-MT и нормализация часов исключены из рабочего интерфейса; старые экспериментальные файлы на диске не используются.

NLLB: CC-BY-NC-4.0; TalTech Whisper: MIT. Лицензия Parakeet: CC-BY-4.0. Локальная сборка не является лицензированным коммерческим дистрибутивом моделей.

### Протокол

Между процессами передаётся JSONL версии 1. Диагностика идёт в stderr.

- `transcript`: session_id, segment_id, revision, status partial/final, text, audio_start/end, emitted_at, inference_ms.
- `translation`: session_id, group_id, revision, segment_ids, status partial/final/error, original, translation, языки, аудиограницы, translation_ms, translation_engine, translation_style.
- Идентификатор сессии отделяет повторяющиеся номера разных запусков. Новая версия группы обновляет прежнюю строку. В историю попадают только завершённые переводы.

### Интерфейс и хранение

`overlay/`: AppKit NSPanel + SwiftUI. Оверлей не перехватывает клавиатурный фокус при обновлении; отдельные окна словаря, карточки, истории и сравнения активируются по действию пользователя. Геометрия окна и настройки сохраняются в UserDefaults. По умолчанию фразы видны 30 секунд: через 10 секунд размер однократно уменьшается до 75%, прозрачность текста — до 80%, затем оба остаются постоянными. Срок показа можно увеличить до 5 минут. Крестик скрывает отдельную карточку, сохраняя запись в истории.

История — дневной JSONL-журнал, читаемый TXT восстанавливается из него. Дата определяется по Europe/Tallinn. Незавершённая последняя запись после прерывания восстанавливается с сохранением исходного файла. Повреждённая середина журнала вызывает ошибку, а не перезапись.

Словарь — версионированный JSON с атомарной записью. Запись включает слово/фразу, значение, исходный контекст и перевод, заметку, дату и язык оригинала. Старый признак закрепления сохраняется только для совместимости с существующими файлами. Совпадение слова и контекста обновляет запись; разные контексты допускаются отдельно. Повреждённый файл не перезаписывается. Перевод выбранного слова выполняется отдельным локальным процессом выбранной NLLB по кнопке; это перевод без контекста, его можно исправить.

Шпаргалка удалена по результатам первого урока: высота оверлея отдана субтитрам. Словарь доступен отдельным окном; сохранённые ранее слова и числа остаются в нём.

Оверлей скрывает фразы, состоящие только из одного или нескольких повторений «Aita» / «Aitäh» (без учёта регистра, пробелов и пунктуации), которые Whisper часто выдаёт на системные звуки. Правило действует на текущую строку и завершённые карточки. Фразы с другими словами показываются как обычно. Исходные сообщения и история сохраняются без изменений.

Метрики карточки: `asr_last_inference_ms` — длительность последнего ASR-прохода для последнего фрагмента группы; `translation_ms` — перевод группы; `since_first_asr_final_ms` — время от первого подтверждённого фрагмента до выдачи перевода, включая накопление и очередь. ASR-проходы не суммируются, поскольку перекрываются и могут выдавать несколько событий. Старые записи без метрик читаются, недоступные значения отображаются прочерком.

При разрезании одного ASR-фрагмента между карточками сохраняются его исходные метаданные; аудиограницы относятся к исходным фрагментам, а не к точной разметке отдельного предложения. В финальном сообщении `remaining_transcripts` передаёт непереведённый хвост для текущей строки оверлея. Каждый законченный текст имеет собственный group_id, предварительный перевод заменяется финальным под тем же ID. CLI `--card-layout groups` оставляет прежнюю группировку для сравнения; штатный режим — sentences. Аудиоокно Whisper сохранено; критерий речевой активности теперь выбирается через Silero или громкость. Длительность паузы остаётся 0,8 секунды.


## Детектор речевой активности

[Silero VAD](https://github.com/snakers4/silero-vad), MIT, v6.2.3, commit `5cd7945676eb32225748052e2e6a0580e4686a08`.
Файл ONNX 2 327 524 байта, SHA256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`.
Загрузчик проверяет SHA256, сохраняет LICENSE и provenance. Используется уже установленный ONNX Runtime без PyTorch и облачных обращений. `vad.py` сохраняет 64 отсчёта контекста и рекуррентное состояние модели, буфер остатка ограничен 511 отсчётами. Детектор не вырезает слова из аудио: он определяет активацию и паузы, а Whisper получает полный накопленный фрагмент.

Проверка на M1: 8 секунд тишины, синтетических стуков, повторных уведомлений Glass и Ping — 0 вызовов распознавания. На 12-секундной эстонской записи и её копии с громкостью ×0,1 распознавание активировалось; VAD около 0,11 мс на 32-мс кадр, около 0,04 с суммарно. Это проверка этих примеров, не гарантия от всех шумов или оценка на реальном уроке. Результаты: `capture-transcription/output/vad-benchmark.json`.

Оверлей поддерживает две колонки одинаковой ширины с переносом текста по высоте и компактными межкарточными отступами. Порог автоматического перехода к вертикальному виду — 600 точек ширины окна. Боковые ручки изменяют ширину с закреплением противоположного края, ограничением минимальной ширины 420 и границами текущего экрана. Геометрия сохраняется при отпускании мыши. Микрофон исключён из дальнейшего развития по решению пользователя: приложение предназначено для речи собеседников из системного звука.

## Потоковый Zipformer

Третий ASR-движок — TalTech streaming Zipformer INT8 через sherpa-onnx 1.13.8 на CPU. Захват, Silero VAD, перевод по предложениям и отображение карточек общие. Вместо повторного распознавания окна Zipformer хранит состояние декодера между порциями PCM. Финальные фрагменты — неизменяемый префикс greedy-результата с удержанием двух последних слов. Пауза/остановка/лимит 16 с завершает оставшийся текст и сбрасывает поток. На тишине ASR не вызывается; перед началом речи сохраняется 0,4 с звука.

События дополнены `asr_engine=zipformer` и `inference_scope=stream_chunk`; перевод переносит scope в `asr_inference_scope`, оверлей сохраняет его как необязательное `recognitionScope` для пояснения статистики. Старые истории читаются без этого поля. Пользовательский выбор ASR сохраняется независимо от выбора NLLB.

Zipformer Large использует тот же потоковый процессор с отдельными весами в `models/zipformer-large-taltech`. Движок `zipformer-large` передаётся через CLI и сохраняется в ASR-событии; пользовательский выбор в меню включает обе версии. Пунктуация из результата декодера сохраняется, автоматической вставки при смене языка нет.

Английский режим `zipformer-en` использует отдельный streaming checkpoint LibriSpeech через тот же процессор. Меню выбирает профиль ASR + язык NLLB; переводчик автоматически выставляет en для этого движка. Caption.sourceLanguage и VocabularyEntry.sourceLanguage — необязательные поля для обратной совместимости (старые записи et). История экспортирует EN/ET по записи; словарный перевод и дедупликация учитывают язык. Заголовок колонки «Оригинал» подходит для оставшихся карточек разных языков после переключения.

Английский поток дополнен Edge-Punct-Casing INT8. Оформляется целиком неподтверждённый хвост, а не отдельные слова. Предложение подтверждается с двумя словами правого контекста; готовые фрагменты не изменяются. Пунктуация и регистр поступают в общий Assembler перед NLLB, оверлеем и историей. Обработка ограничена речевым окном 16 с, одинаковые тексты кешируются, проверяется сохранение слов. Дополнительное время записывается в `punctuation_ms` ASR-событий и диагностику.

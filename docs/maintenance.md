# Сборка и обслуживание

## Установленная версия

`~/Applications/Realtime Translation.app` — локально подписанный macOS bundle. Внутри находится собранный интерфейс; `RealtimeWorkspaceRoot` в `Contents/Info.plist` указывает на рабочую папку проекта. Python-окружения, модели и захват остаются в ней. Запуск не требует терминала, Swift или повторной сборки.

Приложение живёт в строке меню ET. При повторном открытии показывает скрытый оверлей. Оно доступно из Finder и может быть закреплено в Dock. На первом запуске macOS может отдельно запросить доступ к системному аудио для новой идентичности приложения.

## Обновить приложение

Завершите установленное приложение через меню ET. В папке проекта запустите:

```sh
./overlay/build-app.sh
```

Скрипт собирает Swift release, проверяет наличие окружений и захвата, создаёт bundle во временной папке, подписывает локальной ad-hoc подписью, проверяет её и устанавливает в `~/Applications`. Чужое приложение с тем же именем не заменяется. Для другого пути передайте его первым аргументом. После перемещения проекта сборку нужно повторить.

Для запуска исходной версии через терминал остаётся `./overlay/run.sh`. Настройки CLI хранятся в домене `realtime-overlay`, приложения — `local.realtime-translation.overlay`. При первом запуске .app прежние настройки копируются; дальнейшие изменения этих двух способов запуска независимы. История и словарь общие.

Это локальная установка, не переносимый пакет. Для другого Mac потребуется отдельно установить окружения, скачать модели и собрать захват. Подписи Developer ID и нотариализации нет.

## Первоначальная подготовка

Нужны macOS 14.2+, Apple Silicon, Xcode Command Line Tools, uv и доступ к сети для установки. Существующая рабочая машина уже настроена.

```sh
./capture-transcription/setup.sh
./capture-transcription/setup-whisper.sh
./capture-transcription/setup-zipformer.sh # дополнительная потоковая модель
./capture-transcription/setup-zipformer-large.sh # большая потоковая модель
./capture-transcription/setup-zipformer-en.sh # английский потоковый режим
# Setup-скрипты также устанавливают Silero VAD с проверкой SHA256.
./translation/setup.sh
./translation/.venv/bin/python translation/download_nllb13.py
./overlay/build-app.sh
```

Parakeet ожидает существующую модель Handy; путь задаётся через `--model-dir` при отдельном запуске. Whisper и NLLB скачиваются установщиками проекта. OPUS не входит в рабочую конфигурацию.

## Проверки

```sh
capture-transcription/.venv/bin/python -m unittest discover -s capture-transcription/tests
translation/.venv/bin/python -m unittest discover -s translation/tests
swift build --package-path overlay -c release
overlay/.build/release/realtime-overlay --self-test
```

`--demo` запускает искусственные субтитры без захвата и записи пользовательских данных. `--preview-vocabulary /tmp/vocabulary-preview` создаёт снимки интерфейса. `--check-jsonl /path/events.jsonl` проверяет приём сохранённого потока.

Пользователь подтвердил работу системного захвата, эстонских ASR-моделей, перевода, оверлея, истории и словаря. Это не формальная оценка точности на размеченном корпусе. Записи старых измерений лежат в локальных `output/`; они не являются текущей спецификацией.

## Данные и диагностика

Резервируйте `~/Documents/Realtime Translation/`: там история и словарь. Обновление .app их не затрагивает. Ошибки фоновых компонентов пишутся в `~/Library/Logs/Realtime Translation/application.log`; файл больше 5 МБ при следующем запуске заменяется, предыдущий остаётся в `application.previous.log`.

Если звук не поступает, проверьте разрешение на системное аудио и выбранное устройство вывода. После смены устройства остановите и снова запустите захват. Если проект перемещён, повторите сборку .app. При ошибках сохранения интерфейс показывает сообщение — проверьте доступ к папке Documents.

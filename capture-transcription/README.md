# Захват и распознавание

Core Audio taps → mono PCM 16 kHz → Parakeet V3 (CPU) или TalTech Whisper (Metal). Подробности буферов и протокола — в [описании архитектуры](../docs/architecture.md).

Из этой папки:

```sh
./run.sh --engine whisper --interval 3
./run.sh --engine onnx
./run.sh --engine whisper --file /absolute/path/audio.wav --format jsonl
./run.sh --engine whisper --pid 1234
```

Слушается системный звук; микрофон не подключён. По умолчанию CLI использует Parakeet из Handy. Whisper работает с языком et; для отдельных проверок доступны en, ru, auto. Полный список параметров: `./run.sh --help`. Выход можно сохранить через `--output`, продолжительность ограничить `--duration`. Ctrl+C завершает обработку и останавливает захват.

Первоначальная установка: `./setup.sh`, затем `./setup-whisper.sh`. Handy-модель используется только для чтения. TalTech GGML скачивается с закреплённой ревизией и проверкой SHA256. При смене устройства вывода перезапустите захват.

[Сборка и проверки](../docs/maintenance.md) · [TalTech Whisper](https://huggingface.co/TalTechNLP/whisper-large-v3-turbo-et-verbatim-2604) · [AudioTee](https://github.com/makeusabrew/audiotee)

Детектор Silero устанавливается через `.venv/bin/python download_vad.py` (также вызывается setup-скриптами). Для отдельного запуска: `./run.sh --engine whisper --interval 3 --vad silero`. CLI по умолчанию сохраняет energy для совместимости; оверлей явно передаёт выбранный режим.

## TalTech streaming Zipformer

Установка: `./setup-zipformer.sh`. Скрипт сохраняет поддержку Whisper, устанавливает sherpa-onnx и sherpa-onnx-core 1.13.8, скачивает около 71 МБ INT8-модели с проверкой SHA256. Отдельная зависимость core нужна для динамической библиотеки ONNX Runtime в сборке macOS arm64.

```sh
./run.sh --engine zipformer --vad silero
./run.sh --engine zipformer --vad silero --file sample.wav --realtime --format jsonl
```

Модель: https://huggingface.co/TalTechNLP/streaming-zipformer.et-en, MIT, revision `7edbacc1d13a4bc8fba21307753569e8334938a0`. Файлы и provenance находятся в `models/zipformer-taltech`. Работает полностью локально через CPU; GPU не требуется.

`zipformer_backend.py` сохраняет состояние потокового декодера и передаёт каждый новый буфер один раз. `--interval` не задаёт частоту Zipformer: она определяется поступлением звука и внутренними блоками модели. VAD сохраняет 0,4 с перед началом речи; пауза 0,8 с завершает поток. При остановке и лимите окна 16 с остаток декодируется с техническим дополнением тишиной, которое не входит во временные метки. Последние два слова остаются предварительными, остальной префикс greedy-декодера подтверждается для перевода. Метки интервала относятся к текущему речевому окну, не являются точным выравниванием слов. Разрез по лимиту может ухудшать слово на границе.

JSONL совместим с существующим переводчиком. `inference_scope=stream_chunk` обозначает вычисление последнего обновления (включая финальную обработку, если была); это не полная задержка и не сумма обработки фразы.

### Zipformer Large

`./setup-zipformer-large.sh` устанавливает отдельную INT8-модель (~156 МБ), не заменяя обычный Zipformer. CLI: `./run.sh --engine zipformer-large --vad silero`. Переводчик принимает `--asr-engine zipformer-large`. Модель https://huggingface.co/TalTechNLP/streaming-zipformer-large.et-en, MIT, revision `2812262bd4fd5d4327dc09ca0e6c19e8a32a03d6`. Архитектура захвата/потока и greedy-декодирование общие; никакого отдельного восстановления пунктуации нет. Знаки, выданные моделью, сохраняются. Пропущенные моделью знаки могут приводить к более длинным карточкам до паузы или лимита слов. Переключение языка само по себе не считается границей предложения.

Проверка Large на M1 (7 октября 2026): запись 12 с обработалась за 0,84 с без темпа воспроизведения; 19 обновлений, округлённые p50 30 мс / p95 40 мс. Это не измерение полной задержки. На этом примере пропуски пунктуации остались; улучшение качества относительно малой модели не подтверждено. Локальный отчёт: `output/zipformer-large-smoke-test.json`.

## Английский Zipformer

Установка: `./setup-zipformer-en.sh`; запуск: `./run.sh --engine zipformer-en --vad silero`. Потоковый INT8 checkpoint `csukuangfj/sherpa-onnx-streaming-zipformer-en-2023-06-26`, revision `672fbf1b30579d6585301139bb363f42a0ad4a24`, Apache-2.0, около 73 МБ. Используются chunk-16 / left-128 файлы; установщик сохраняет их под стандартными локальными именами, исходные имена и SHA256 записаны в provenance. Общий потоковый процессор, CPU и Silero VAD. Модель обучена на LibriSpeech; для неё автоматически включена Edge-Punct-Casing INT8.

### Английская пунктуация и регистр

`setup-zipformer-en.sh` также устанавливает Edge-Punct-Casing (Apache-2.0): 7,49 МБ INT8 + 149 КБ BPE. Архив release 2024-08-06, SHA256 архива и отдельных файлов закреплены в `download_punctuation.py`; установщик извлекает только проверенные файлы. Веса находятся в `models/punctuation-en`, происхождение записано в provenance. После установки работа полностью локальная, CPU, один поток. При отсутствии модели английский режим сообщает явную ошибку установки.

`punctuation.py` оформляет предварительный текст и проверяет, что последовательность распознанных слов сохраняется; при неожиданном изменении слов возвращается исходный текст. Повторное оформление одинакового текста кешируется. В английском режиме `ZipformerProcessor` подтверждает предложения, когда после предсказанного окончания поступили минимум два следующих слова; оставшийся текст остаётся предварительным. На паузе/остановке финализируется остаток; если терминального знака нет, добавляется точка. На лимите окна этот искусственный знак не добавляется. Типовые английские титулы с точкой не завершают предложение. Эстонские Zipformer используют прежний алгоритм.

`punctuation_ms` в ASR-событиях и итоговая диагностика показывают дополнительное время оформления. Показатель «Речь» по-прежнему измеряет вычисление ASR и не включает пунктуацию. Вычисление оформления на коротких фразах M1 заняло около 7–10 мс; задержка подтверждения предложения дополнительно зависит от поступления следующих слов. Пунктуация — предсказание по тексту и может ошибаться.
